Jak pobrać dane API ze Stravy?

Client ID i Client Secret są potrzebne, aby Trener AI mógł połączyć się z Twoim kontem i pobierać aktywności.

  1. Otwórz ustawienia API Stravy

    Zaloguj się do Stravy w przeglądarce i przejdź do strony My API Application.

  2. Utwórz aplikację

    Jeśli nie masz jeszcze aplikacji, uzupełnij jej nazwę, kategorię i stronę internetową. Możesz użyć nazwy „Trener AI”.

  3. Ustaw domenę zwrotną

    W polu Authorization Callback Domain wpisz domenę, pod którą działa Trener AI, bez https:// i bez ścieżki. Lokalnie wpisz localhost.

  4. Skopiuj dane

    Po zapisaniu aplikacji znajdziesz wartości Client ID oraz Client Secret. Secret może wymagać kliknięcia „show”.

  5. Zapisz je w Trenerze AI

    Przejdź do Ustawień, wklej obie wartości do pól Stravy i kliknij „Zapisz ustawienia”. Następnie w panelu wybierz „Połącz ze Stravą”.

Ważne

Client Secret traktuj jak hasło — nie publikuj go ani nie wysyłaj innym osobom.
